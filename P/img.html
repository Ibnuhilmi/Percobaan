Setiap tag HTML dapat memiliki satu atau lebih atribut, atribut ini berfungsi untuk menyimpan informasi yang berkaitan dengan tag tersebut. Pada tag kalian akan menggunakan atribut src untuk mengambil lokasi penyimpanan image yang akan ditampilkan. Dapat dilihat kalian sudah memiliki atribut src dimana atribut src akan kalian arahkan ke tempat lokasi image disimpan atau kalian juga bisa menempatkan link url image jika ingin mengambil dari document eksternal. Dan pada tag kalian tidak perlu menggunakan tag penutupnya Tutorial memuat image Setelah kalian memahami tag tersebut sekarang waktunya kalian mencobanya: 1. buatlah folder yang didalamnya terdapat image, file html. 2. pastikan kalian mengingat tempat lokasi image-nya misalkan (lokasi: html/img/yourImage.jpg). 3. code HTML: Judul File HTML

ini adalah contoh pemuatan gambar pada file HTML

Hasilnya: image.png Atribut optional img Setiap tag img, selain memiliki atribut src untuk menyimpan lokasi gambar, anda juga harus menyertakan atribut alt yang akan digunakan sebagai teks alternatif ketika gambar tidak berhasil dimuat atau gambar hilang. Dan atribut lainnya adalah atribut width dan height, yang berfungsi untuk menentukan lebar dan tinggi dari gambar tersebut. Memang hal ini tidak perlu dilakukan karena gambar secara otomatis akan terload dengan ukuran sebenarnya, namun hal ini sangat dianjurkan untuk mempercepat proses pemuatan gambar. tetapi sangat disarankan lebih baik kalian jika ingin menggunakan atribut width dan height pilihlah salah satunya saja seperti code diatas hal itu dilakukan agar gambar kalian tampil responsive.
